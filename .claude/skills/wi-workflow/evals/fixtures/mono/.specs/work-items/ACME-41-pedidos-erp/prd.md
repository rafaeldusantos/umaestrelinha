# PRD — Exportar pedidos para o ERP

## Casos de uso

- **UC-01 — Listar pedidos a exportar.** A listagem mostra os pedidos em páginas.
- **UC-02 — Status do pedido.** O status é um de: novo, pago, enviado, entregue, cancelado.
- **UC-03 — Arquivo de exportação.** O arquivo se chama dump e vai ao ERP uma vez por dia.
