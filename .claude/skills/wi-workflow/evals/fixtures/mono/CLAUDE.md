# acme-app

Front e API de pedidos da Acme num repositório só (TypeScript, Vite, Express, vitest).

## Comandos

- Lint: `npm run lint`
- Testes: `npm run test:run`

## Convenções

- Regra de negócio em `src/<domínio>/`, um arquivo por caso de uso, teste ao lado (`*.test.ts`)
- Telas em `src/pages/`, uma por rota
