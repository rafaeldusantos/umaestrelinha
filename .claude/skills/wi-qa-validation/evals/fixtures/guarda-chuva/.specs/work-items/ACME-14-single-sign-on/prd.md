# PRD — Single sign-on com Azure AD

## Problema

Hoje cada pessoa tem uma senha própria no Acme; o RH quer que o acesso siga a conta corporativa.

## Critérios de aceite

- P1-AC01: o usuário entra pelo Azure AD e volta logado
- P1-AC02: o logout encerra a sessão também no IdP

## Expectativas de UI/UX

Nenhuma fonte de design informada. O botão segue o padrão visual dos botões secundários da tela de login.

## Fora do escopo

- Provisionamento automático de usuários (SCIM)
