# Nanita Store

## Vision
Loja virtual de pin buttons temáticos de cultura pop (anime, K-Pop, games, filmes, séries). E-commerce D2C focado em colecionadores e fãs.

## Stack
- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + shadcn/ui + Framer Motion
- **Backend**: Supabase (Auth, Database, Storage, Edge Functions)
- **State**: Zustand (cart, wishlist) + React Query (server state)
- **Routing**: React Router v6

## Goals
- Experiência de compra vibrante e pop culture-focused
- Mobile-first, performance otimizada
- Design system consistente com identidade visual forte
